HMI PROJECT - BUILD AND RUN STEPS
=====================================

This document contains all the steps I followed to build and run the various components of the HMI project.

PROJECT OVERVIEW
================
The HMI project contains multiple sub-projects:
1. OpenMU - MMORPG game server (C#/.NET)
2. DotSpatial - GIS mapping library
3. GeoBlazor - Blazor-based mapping components
4. MonolithicGeoApp - Geospatial console application
5. GeoCountriesApp - Blazor web app for country data
6. Various other geospatial utilities

2. OPENMU GAME SERVER SETUP
---------------------------
Description: Set up and run the OpenMU MMORPG server using Docker

Steps Followed:
a) Navigate to OpenMU deployment directory:
   cd /workspaces/HMI/OpenMU/deploy/all-in-one

b) Start services using Docker Compose:
   docker compose up -d

c) Verify services are running:
   docker compose ps

d) Check service logs:
   docker compose logs -f openmu-startup
   docker compose logs -f database
   docker compose logs -f nginx-80

Results:
- PostgreSQL Database running on port 5433
- Game Servers running on ports 55901-55906
- Connect Servers on ports 44405-44406
- Chat Server on port 55980
- Admin Panel accessible at http://localhost (port 80)
- Default admin credentials: admin/openmu

Status: ✅ SUCCESSFULLY RUNNING

MAINTENANCE COMMANDS
===================

Stop all OpenMU services:

View service status:
docker compose ps

View logs:
docker compose logs -f [service-name]

Restart services:
docker compose restart
