# Monolithic Geospatial WinForms App

A minimal Windows Forms application with embedded geospatial data and UI.

## Features
- ✅ Windows Forms UI
- ✅ Embedded city coordinates (8 cities)
- ✅ Interactive map visualization
- ✅ Distance calculations using NetTopologySuite
- ✅ Single executable - all code in one project

## Run on Windows

```bash
cd MonolithicGeoApp.WinForms
dotnet run
```

## Usage
1. Select 2 cities from the list
2. Click "Calculate Distance"
3. See distance and visual connection on map
